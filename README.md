# LEO Satellite Ground Station Prototype

A hands-on undergraduate project focused on the design and development
of a software-defined LEO satellite communication ground station.

## Project Areas

- Satellite communication
- RF and antenna fundamentals
- Link-budget analysis
- Free-space propagation
- Thermal noise and SNR
- Satellite geometry
- Doppler modeling
- Digital communications
- GNU Radio / SDR
- HFSS antenna design
- Experimental RF measurements

## Current Status

The initial mathematical model has been developed, including:

- Wavelength calculation
- Free-space path loss
- Basic link budget
- Thermal noise
- Receiver noise figure
- SNR
- Link margin
- Simplified satellite geometry
- Doppler shift

The next stage is realistic satellite-pass modeling and development of
the GNU Radio communication chain.

## Project Structure

- `theory/` — theoretical derivations and explanations
- `python/` — mathematical and simulation models
- `gnuradio/` — GNU Radio flowgraphs
- `hfss/` — antenna simulations
- `matlab/` — MATLAB simulations
- `results/` — plots, tables and experimental results
- `data/` — external datasets and recorded signals
- `docs/` — development logs and technical documentation
